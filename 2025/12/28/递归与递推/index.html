递归与DFS（深度优先搜索）

递归就是在一个函数里调用函数自身的编程手段。会产生一棵递归搜索树，在数据量较小的时候可以用，它的时间复杂度是指数级别的。如： $ O(2^n) $ 。

递归是把一个大问题分解成若干个子问题，得到子问题答案再层层返回求得大问题答案。

DFS是一种算法。DFS优先沿着一条路径走到结尾再回溯到上一个节点，继续探索其他分支。在实现上主要由三部分组成：

  • 结束条件 （到达底部）
  • 选择分支
  • 状态恢复（回溯的时候用）

思路（以dfs的搜索树为例）：

  1. 思考结束条件：到树底了该怎么判断，然后要做什么（输出结果之类的），最后记得 return。
  2. 思考选择分支：一个节点有几个分支（比如for循环一个个选过去），要如何处理（就是主要的函数实现，比如把选择的人存进数组），然后判断在哪里递归调用（选完了，递归调用进入下一层节点的选择）。
  3. 思考状态恢复：递归调用结束，要把递归的造成的影响复原，清除标记（如果有），复原状态（比如：状态数组）。

枚举 与 排列组合

枚举是列出所有的可能结果。用DFS来枚举时，可以先暴力枚举（注意时间），然后再剪枝优化（考虑一些判断条件，不合法的直接return）。

递推

递推是先知道子问题答案，再一步步求得大问题答案。（斐波那契先给出第一项和第二项从而求出后面的数就是）

几个c++函数

  • next_permutation:是 C++ 标准库的函数，用于生成序列的下一个字典序排列。如果当前排列有下一个符合字典序的排列则生成下一个排列并返回true，如果是最后一个，则返回到第一个排列（升序）,并返回false。它定义在 <algorithm> 头文件中。
    • 用法： next_permutation(数组首地址,数组尾地址);
    • 函数里面的两个参数本质是随机访问迭代器，指针天然有这个属性，直接用迭代器也可以。
    • 这个函数会改变原数组，如果需要，要注意备份。
    • 如果想要得到全部的符合字典序的排列，需要保证初始时为最小排列。
    • 按字典序枚举：
  • memset：用于将一段内存区域设置为指定的值。可以用于大量初始化为0或特定值。
    • 函数原型：void* memset(void* ptr, int value, size_t num);
    • ptr:起始地址 value:设置的值 num:设置的字节数
    • 头文件依赖：cstring（c++）string.h(c)
    • 常用设置所有字节：memset(arr,0,sizeof(arr)); //全数组设置为0
  • memcpy： 用于内存数据拷贝，是以二进制的方式，无需关心数据类型。
    • 函数原型：void *memcpy(void *dest, const void *src, size_t n);
    • dest:目标内存地址 src:源内存地址 n:要复制的字节数
    • 头文件依赖：cstring（c++）string.h(c)
    • 完整复制一个数组：memcpy(destArr,srcArr,sizeof(srcArr));
