async/await学习

2026/5/9 front-end ES6

写在前面：今天了解了“函数”和“方法”的区别，之前的有些说法可能有些不合适，今后改。

  • 函数（Function）：
    • 一个独立代码块，不属于任何类和对象
    • 通过接收参数输入，处理，返回结果
    • 在面向过程编程中比较多
    • 一般是 函数名(参数)
  • 方法（Method）
    • 本质和函数差不多
    • 但是依赖于特定的类和对象
    • 在面向对象编程中比较多
    • 一般是 对象（或类）.方法名(参数)

async和await学习

async和await的语法和返回值

  • async用于修饰函数，被修饰的函数会返回一个Promise对象
    • 语法： async function function() { ... }
    • 该关键字只能加在函数前面（普通函数，箭头函数和类方法都可以）
    • 因为会返回一个 Promise 对象，所以async函数可以用 .then()、.catch() 链式调用
    • 可以在另一个 async函数 里，用 await 来调用
  • await只能在 async函数里面调用，会让代码在该行 “暂停” ，等后面的Promise “成功” 再继续。
    • 语法：
      • 后跟Promise： let res1 = await Promise.resolve("成功处理") ， 等resolve处理
      • 后跟普通值： let res2 = await 'abc' ,等价于await Promise.resolve('abc');
      • 后跟函数调用： let res3 = await(() => '函数返回值')() ,会先执行函数，再await函数返回值
