十二、日常标准开发流程（记住这套就能独立开发）

单人开发流程

  1. 修改代码
  2. git status 查看变更
  3. git add . 加入暂存
  4. git commit -m "更新描述"
  5. git pull 拉取远程最新
  6. git push 推送

多人协作规范流程

  1. git pull 拉取最新代码
  2. 创建功能分支 git switch -c feature/xxx
  3. 写代码、提交
  4. 推送分支 git push -u origin feature/xxx
  5. GitHub提交PR合并到main
  6. 合并完成后切回main，git pull 更新本地
