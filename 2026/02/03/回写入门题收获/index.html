<iomanip>库

<iomanip> 是 C++标准库 中的一个头文件，它提供了对输入/输出流的格式化操作。iomanip 库中的函数允许开发者控制输出格式，如设置小数点后的位数、设置宽度、对齐方式等。iomanip 是 Input/Output Manipulators 的缩写，它提供了一组操作符，用于控制 C++ 标准库中的输入/输出流的格式。

<cmath>库

C++ 标准库提供了丰富的功能，其中 <cmath> 是一个包含数学函数的头文件，它提供了许多基本的数学运算和常数。<cmath> 是 C++ 标准库中的一个头文件，它定义了一组数学函数，这些函数可以执行基本的数学运算，如幂运算、三角函数、对数、绝对值等。

常用：

  • abs(x) 返回整数x的绝对值
  • fabs(x) 返回浮点数x的绝对值
  • fmax(x,y)、fmin(x,y) 比较x和y返回较大（小）值
  • pow(x,y) 计算 x 的 y 次方
  • sqrt(x) 计算 x 的平方根
  • cbrt(x) 计算 x 的立方根
  • ceil(x) 返回不小于 x 的最小整数（向上取整）
  • floor(x) 返回不大于 x 的最大整数（向下取整）
  • round(x) 返回四舍五入到最接近的整数
  • lround(x) 返回四舍五入到 long 类型
  • llround(x) 返回四舍五入到 long long 类型
  • sin(x)
  • cos(x)

素数筛

素数(质数)是指在大于 1 的自然数中，除了 1 和它本身以外不再有其他因数的自然数。

  1. 素数是自然数，是整数。
  2. 素数大于1
  3. 素数只有1和它本身两个因数
  4. 最小素数是2

试除法

思想：直接一个一个除过去

埃式筛（埃拉托斯特尼筛法）

思想：素数的整数倍一定是合数，在一个自然数集合里，只需要把所有合数标记出来，剩下的都是素数了。

埃式筛还是会重复标记一些已经筛过的素数，所以接下来我们看看欧拉筛。

欧拉筛（线性筛）

思想：任何大于1的正整数n都可以唯一分解为有限个素数的乘积。任何合数都有它对应的一个最小质因子。可以通过这个最小质因子将其标记，这样可以避免重复标记。（整数唯一分解定理）

  • 总结一下就是先把所有数标记为素数。从2开始找，遇到素数就加进素数数组，然后用当前的数作为倍数，分别乘上所有目前已经知道的素数，并将其标记为合数，直到走到n-1。
  • 比如当前数是2，2是素数，这样就将2放入素数数组，并将目前素数数组里的素数（目前只有2）作为质因子，以当前数为倍数，筛掉合数。素数数组里的素数就是作为最小质因子。（每个数的最小质因子只有一个，4的最小质因子是2，6的最小质因子也是2，他们都只会被素数数组里的“2”筛掉，这样就不会重复筛）

一些写题注意事项

  • 数组长度可以设稍大一些，防止越界（比如字符串输入末尾的’\0’）
  • 当你需要一个依赖输入的vector时，可以先声明，再分配内存。这样可以防止越界。防止越界很重要。看到数组要小心越界。特别在循环里，一个变量++遍历时可以考虑XXX.size()来判断
